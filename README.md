# USMLE 데일리

USMLE Step 1 self-study app: 677 original practice questions, spaced-repetition review, timed 40-question blocks, and per-system stats.

- Live: https://drberrybear.github.io/usmle-daily/
- Progress is saved in this browser only (localStorage).
- Friends leaderboard, challenges, AI-generated questions, and phone↔PC sync are available in the claude.ai version.

All questions were written for this project and are not taken from any commercial question bank.
